# Roadly — Automotive Marketplace Demo

Interactive client demo for an automotive marketplace concept combining:

- Fuel price discovery
- Local mechanics
- Towing / roadside assistance
- Auto-parts stores
- Pay-per-lead monetization for service providers
- Business lead wallet and unlock flow

## Demo

Open `index.html` directly in a browser, or serve the repository with any static web server.

The map uses OpenStreetMap tiles through Leaflet. All business names, prices, lead details and contact information shown in the prototype are sample/demo data and are not intended as live market data.

## Product direction

The prototype is intentionally front-end only. A production build can later connect approved providers for maps/fuel data, authentication, business onboarding, lead payments, notifications, analytics and a real backend.

## Visual direction

Warm ivory base with coral, lime, violet, mint and amber accents. The UI is mobile-first and avoids the usual dark-blue SaaS aesthetic.
